NovelHub V2 — site estático, sem banco e sem backend.

Astralia foi adicionada como a primeira e única novel, com o Capítulo 1 fornecido.

Para novas novels: crie uma pasta em /novels, coloque capítulos HTML, uma capa em /images e adicione os dados em /data/novels.json.

Se o navegador bloquear fetch ao abrir index.html diretamente, use Live Server do VS Code para testar localmente. Isso não adiciona backend ao projeto.
